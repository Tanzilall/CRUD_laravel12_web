# 📱 Aplikasi CRUD Data Laptop

Aplikasi sederhana untuk mengelola data laptop dengan fitur **Create, Read, Update, Delete** (CRUD) menggunakan Laravel 13.

## ✨ Fitur

- ✅ **Create** - Menambah data laptop baru
- ✅ **Read** - Menampilkan daftar laptop dan detail per laptop
- ✅ **Update** - Mengedit data laptop yang sudah ada
- ✅ **Delete** - Menghapus data laptop
- ✅ **Pagination** - Pagination untuk data yang banyak
- ✅ **Responsive Design** - Tampilan responsif dengan Tailwind CSS
- ✅ **Alert Message** - Notifikasi sukses/error

## 🛠️ Teknologi yang Digunakan

- **Framework**: Laravel 13
- **Database**: MySQL
- **Frontend**: Blade Template + Tailwind CSS
- **PHP**: PHP 8.3
